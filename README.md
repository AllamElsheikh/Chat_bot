# 🧠 Instruction-Tuned Chatbot with LoRA & T5

A simple instruction-following chatbot built with `Flan-T5`, LoRA fine-tuning, and a conversational interface using Streamlit or Gradio.

## 📁 Project Structure

Chat-bot/ 
-  ├── model_loader.py # Loads model and tokenizer
-  ├── load_the_data.py
-  ├── loging_to_huggingface.py
-  ├── prepare_the_data.py
-  ├── train_the_model.py
-  ├──build_the_model.py
-  ├── app.py # Chatbot interface (Streamlit or Gradio)
-  ├── requirements.txt
-  └── README.md
